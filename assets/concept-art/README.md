# Project Slit 콘셉트 아트

이 디렉터리는 CxC Lab이 직접 제작하거나 생성한 Project Slit 콘셉트 아트를 보관한다.

- 콘셉트 아트는 비주얼 방향을 논의하기 위한 자료이며 최종 게임 화면이나 출시용 에셋이 아니다.
- 파일명에는 주제와 버전을 식별할 수 있는 이름을 사용한다.
- 중요한 이미지는 관련 분석 문서와 연결한다.
- 외부 게임의 아트는 이 디렉터리에 자체 제작물처럼 보관하거나 출시 에셋으로 사용하지 않는다.

현재 기준 이미지는 [`project-slit-gameplay-concept-v001.png`](project-slit-gameplay-concept-v001.png)이며, 분석은 [`docs/visual-direction.md`](../../docs/visual-direction.md)에 기록한다.
