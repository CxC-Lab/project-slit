# Project Slit 개발 스크린샷

이 디렉터리는 문서에서 참조하는 개발 중 게임 화면을 보관한다.

- 개발 과정을 보여주는 자료이며 완성된 게임 화면이 아니다. 임시 그레이박스 지형과 진단용 색이 그대로 보일 수 있다.
- 파일명에는 지역과 무엇을 보여주는지, 날짜를 넣는다. `avatar_lake-tile-greybox-2026-09-12.png` 형식이다.
- 플레이 중 `F12` 로 찍은 것은 `build/preview/captured_NNNN.png` 에 쌓이며 저장소에 포함되지 않는다. 그중 문서에 남길 것만 이름을 바꿔 여기로 옮긴다.
- 같은 화면을 갱신할 때 기존 파일을 덮어쓰지 않는다. 날짜가 다른 새 파일로 두고 문서의 링크를 옮긴다. 과거 기록이 남아야 한다.
