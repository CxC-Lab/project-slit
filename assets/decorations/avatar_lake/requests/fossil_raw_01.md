# 기계 암모나이트 화석 raw 01 생성 요청서

- 대상: ChatGPT 이미지 생성
- 계약: 데코레이션 레이어 최소 설계안(2026-09-15 승인). 지형 경계 계약은 [`docs/decisions/0011-terrain-boundary-assets.md`](../../../../docs/decisions/0011-terrain-boundary-assets.md)
- 받을 파일: `assets/decorations/avatar_lake/source/fossil_raw_01.png`
- 상태: **주력 지면 암모나이트로 승인(2026-09-16).** 승인 에셋 `runtime/fossil01_ammonite.png`(64×48, sha256 `a6c67e8a…16fc`), `behind` 로 (275, 501)과 (886, 541, 좌우 반전). 전경 없음. 지형이 앞에 그려져 top 이끼가 하단을 가린다. 같은 raw01 의 48×36 `above` 후보는 윗면 이끼를 덮어 붙여 넣은 오브젝트처럼 보여 불채택했다(시험 파일은 삭제, 기록만 남김). 원본 `source/fossil_raw_01.png` sha256 `1d58e0db…8844`. 결정은 ADR 0012
- 이 화석은 **충돌이 없는 장식**이다. 지형 타일이 아니며 플레이어가 밟거나 막히지 않는다

## 규격

| 항목 | 값 |
| --- | --- |
| 런타임 결과 | 64x48 RGBA. 가로가 긴 4:3 (48x36 은 작아서 2026-09-15 폐기) |
| 생성 원본 | 가로가 긴 이미지 한 장. 1024x768 이상 권장(4:3). 화석 하나만 |
| 축소 배율 | 가로세로 같은 배율. 원본 1024x768 이면 약 21배 |
| 픽셀 밀도 | 이미지 가로를 약 48칸으로 나눈 격자에서 한 칸이 게임 픽셀 하나. 승인 암반 E0 와 같은 굵기감 |
| 알파 | 0 또는 255. 정규화가 만든다 |
| 팔레트 | 투명 제외 12색 이하. 그중 절반 이상은 E0 암반 색 계열 |
| 좌우 반전 | 허용. 좌우 방향 조명을 넣지 않는다 |

## 색과 재질

- **암반 부분:** 첨부한 E0 암반의 주황·보라·회갈색 그대로다. 새 암반 색을 만들지 않는다.
- **금속 부분:** 무광 청동·황동 계열의 어두운 금속이다. 광택 하이라이트는 한두 칸 점으로만 쓴다.
- **부식:** 금속 표면에 청록색 녹을 아주 조금 넣는다. 전체의 10% 이하다.
- **발광:** 없다. 빛나는 코어, 네온, 발광 문양을 넣지 않는다.
- **조명:** 위에서 오는 빛만 쓴다. 좌우 방향 그림자를 넣지 않는다.

## 구도

- 나선형 암모나이트 껍데기 하나가 옆에서 보이게 놓인다. 나선 홈이 톱니바퀴나 기계 부품처럼 규칙적으로 새겨져 있다.
- **묻히는 비율:** 화석의 아래쪽 40% 정도가 암반에 묻혀 있고, 그 부분은 암반 픽셀과 뒤섞여 경계가 불규칙하다.
- **기준점:** 이미지의 아래 가장자리 중앙이 배치 기준점이다. 게임에서 이 점을 지형 표면 아래 위치에 맞춘다.
- 위쪽 60%는 암반 밖으로 드러난 껍데기다.

## 배치 (게임 쪽 정보)

- **레이어:** 지형 뒤(`behind`). 지형이 화석 위에 그려져 묻힌 부분이 실제로 가려진다. `above` 는 윗면 이끼를 덮어 붙여 넣은 것처럼 보여 2026-09-15 폐기
- **첫 배치 좌표:** 사용자가 2026-09-15 플레이 중 지정한 두 곳을 쓴다. 기준점이 이 좌표에 온다
  - (275, 501) 스폰 오른쪽 작은 단 윗면(y=480)에서 21px 아래
  - (886, 541) 첫 굴다리 앞 지면(y=520)에서 21px 아래, 좌우 반전
  - 껍데기의 위 63%만 지면 위로 드러나고 암반 받침은 전부 가려진다
  - 주문서 초안의 (8250, -1180)은 기둥 몸통 속이라 '위 60% 드러남' 그림과 맞지 않아 폐기했다
- 충돌은 없다. 플레이어는 그대로 지나간다

## 배경과 알파 처리

- 배경은 전체를 선명한 마젠타 단색(`#FF00FF`에 가까운 색)으로 채운다. 그라데이션, 그림자, 바닥, 무늬를 넣지 않는다.
- 화석과 배경 사이에 섞인 중간색, 번짐, 후광이 생기지 않게 경계를 또렷하게 한다.
- 정확한 배경색과 이진 알파는 raw 의 책임이 아니다. 정규화가 처리한다.

## 정규화와 팔레트 절차

1. 원본을 `source/` 에 받은 그대로 두고 편집·리사이즈하지 않는다.
2. 고정 crop 하나를 매니페스트에 적는다. 가로세로 비는 정확히 4:3 이다.
3. 원본 해상도에서 배경을 분리하고, 마젠타 쪽으로 기운 가장자리 픽셀을 제거한다.
4. 보간 없이 48x36 으로 점 표본 축소한다.
5. 불투명 픽셀에서만 팔레트를 뽑는다. 투명 제외 12색 이하다.
6. 알파는 0 또는 255 로 출력한다. 팔레트에 배경색이나 마젠타 쪽 색이 남으면 실패다.
7. 결과는 시험 데코레이션으로만 쓰고, 플레이 판정 뒤에 승격한다.

## 금지

- 발광, 네온, 마법 효과
- 눈, 얼굴, 캐릭터처럼 보이는 형태
- 글자, 숫자, 기호, 서명
- 원근법, 비스듬한 시점, 입체 렌더링 느낌
- 부드러운 그라데이션, 안티에일리어싱, 흐림, 사진 질감
- 화석 주변의 흙더미, 풀, 이끼, 덩굴(식물은 별도 에셋이다)
- E0 에 없는 새 암반 색
