## 1. 최종 시각 목표

깨끗한 화석을 지면 뒤에 숨기는 장면이 아니다. 화석은 **top 이끼를 관통해 inner 암반까지 깊게 박혀 있고**, 화석 표면에도 이끼와 흙, 암반이 붙어 있다. 최종 게임 화면에서 다음 세 재질이 하나의 지층처럼 섞여 보여야 한다.

- 무광 황동 기계 화석
- 승인된 top 이끼
- 승인된 E0 inner 암반

화석과 지형 사이에 명확한 접촉선이 남거나, 깨끗한 금속 오브젝트를 나중에 지형으로 가린 것처럼 보이면 **실패**다.

## 2. 크기 결정: 96×72 채택

| 조건 | 목표 | 80×60 | **96×72** |
| --- | --- | --- | --- |
| 지면 위 노출 | 30~36px | 최소 30 은 가능 | **34px** |
| 지면 아래 | 22~28px | 최소 22 는 가능 | **24px** |
| 순수 inner 침투 | 6~12px | 6px(하한), 아래 여백 4행 | **8px**, 아래 여백 8행 |
| 상한 조건(노출 36 + 아래 28) | — | 화석 60행이 캔버스 전체를 채워 **넘친다** | 여유 있음 |
| 화석 크기 | 대표 발견 오브젝트 | 56×52 | **62×58** (플레이어 32×48 대비 가로 약 2배) |

80×60 은 조건의 하한 모서리에서만 성립하고 여백이 없어, 정규화 오차 1~2행에도 순수 inner 침투가 사라진다. assembly_v3(80×60)에서도 순수 inner 까지 닿은 화석은 0px 이었다. **96×72 를 채택한다.**

## 3. 캔버스 지도 (96×72)

생성 원본은 **정확히 1440×1080**(4:3, 게임 픽셀 1칸 = 15×15)으로 만든다. 원본 캔버스 전체가 96×72 에 대응하고 피사체에 맞춰 잘라내지 않는다. 아래 비율은 캔버스 기준이다.

### 행

| 행 | 캔버스 높이 비율 | 게임에서 | raw04 에 그릴 것 |
| --- | --- | --- | --- |
| 0 ~ 5 | 0 ~ 8% | 하늘 | 비워 둔다 |
| 6 ~ 39 | 8 ~ 56% | **지면 위 노출 34px** | 화석 윗부분. 나선 중심 포함 |
| 40 | 56% | **지형 표면선** | 화석이 이 선을 가로질러 계속된다. 선을 의식한 경계를 그리지 않는다 |
| 40 ~ 55 | 56 ~ 78% | **top 구간 16px** | 화석 하단이 계속된다. 이끼·흙 부착물이 늘어난다 |
| 56 ~ 63 | 78 ~ 89% | **순수 inner 침투 8px** | 화석 가장 아랫부분. E0 암반 부착물이 가장 많다 |
| 64 ~ 71 | 89 ~ 100% | inner | 비워 둔다 |

- 기준점: 캔버스 아래 가장자리 중앙 = **지형 표면 + 32px**
- 허용 오차: 화석 윗끝 4~10행(노출 30~36px), 아랫끝 61~67행(지면 아래 22~28px)

### 열과 나선

| 항목 | 열 / 행 | 캔버스 비율 |
| --- | --- | --- |
| 화석 좌우 범위 | 17 ~ 78열 (62px) | 가로 18 ~ 82% |
| 화석 상하 범위 | 6 ~ 63행 (58px) | 세로 8 ~ 89% |
| **나선 중심** | **약 57열, 29행** | **가로 59%, 세로 40%** |
| 나선 중심의 지면 위 높이 | 11px | 허용 22~32행, 50~64열 |

나선 중심은 스케치처럼 **화석 중앙보다 오른쪽**에 두고, 지면 위 노출 구간 안에서 약 2/3 높이에 온다.

### 면적

화석 영역 약 2,836px 기준으로 지면 위 61%, top 구간 31%, 순수 inner 8% 다. 최종 합성에서 보이는 비율 목표는 **55~65%** 다(아래 8절).

## 4. raw04 에 직접 그릴 것

raw04 는 깨끗한 금속 화석이 아니다. **오랫동안 Avatar Lake 암반에 묻혀 있던 하나의 기계 암모나이트 화석**이다.

### 화석 본체

- 하나의 크고 일관된 암모나이트 형상. 나선 중심, 주요 외륜, 갈빗살이 연결되어 있다.
- 외곽과 갈빗살의 **70~85% 는 끊기지 않고 이어지고**, 나머지 15~30% 만 부착물과 마모로 끊긴다.
- raw03 처럼 여러 파편으로 해체하지 않는다.
- 장식용 톱니바퀴나 배지처럼 정돈하지 않는다. 기계 마디는 있으나 닳고 막혀 있다.
- **하단 형상을 끝까지 그린다.** 63행 근처까지 둥근 몸체가 이어지고, 게임에서 top 과 inner 안쪽으로 들어간다.
- 평평한 하단선이나 받침돌이 없다.
- 위쪽 호는 화석으로 읽히도록 유지하되 일부는 부착물과 마모로 끊긴다.
- 위에서 오는 빛만 쓴다. 좌우 방향광 없음.
- 발광, 네온, 마법 효과 없음.

### 화석 표면의 부착 오염

- 금속 홈과 갈빗살 사이에 E0 계열 흙과 암반 가루가 끼어 있다.
- 암반 조각 일부가 외륜 위에 단단히 붙어 있다.
- **왼쪽 아래:** 승인된 top 과 같은 이끼가 금속 홈을 따라 올라간다. 아래는 조밀하고 위로 갈수록 끊긴다.
- **중앙 아래:** 이끼, 흙, 금속이 짧고 불규칙하게 뒤섞인다.
- **오른쪽 아래:** E0 암반색이 외륜과 갈빗살 일부를 잠식한다.
- 부착물은 화석의 둥근 굴곡과 갈빗살 방향을 따른다.
- 이끼와 암반이 화석 외곽 전체를 일정한 간격으로 두르면 실패다.
- 부착물은 **아래로 갈수록 많아진다.** 40행 아래(top 구간)부터 눈에 띄게 늘고, 56행 아래(순수 inner)는 암반 부착물이 가장 많다.

### 권장 면적 (화석 영역 기준)

| 재질 | 비율 |
| --- | --- |
| 무광 황동 | 약 65~75% |
| E0 흙·암반 부착물 | 약 15~25% |
| top 이끼 | 약 5~10% |

정확한 비율보다 자연스러운 결과를 우선한다. 다만 깨끗한 황동 장식품처럼 보이면 실패다.

## 5. raw04 에 그리지 않을 것

raw04 의 부착 오염과 실제 지형 연결은 구분한다. 실제 타일과 이어지는 넓은 전경은 정규화 이후 게임 쪽에서 따로 만든다.

- 화석 아래의 완성된 지면
- 좌우로 길게 이어지는 top 이끼띠
- 위치가 고정된 완성형 inner 배경
- 평평한 흙 또는 암반 받침
- 화석 전체를 받치는 큰 둔덕
- 외곽 전체를 따라가는 이끼나 암반 테두리
- 눈, 얼굴, 캐릭터처럼 보이는 형태
- 글자, 숫자, 기호, 서명
- 원근법, 비스듬한 시점, 입체 렌더링 느낌
- 부드러운 그라데이션, 안티에일리어싱, 흐림, 사진 질감

## 7. 배경과 정규화 계약

1. 배경은 전체를 선명한 마젠타 단색(`#FF00FF` 에 가까운 색)으로 채운다. 그라데이션, 그림자, 바닥, 무늬 없음. 화석·부착물과 배경 사이에 섞인 중간색이나 후광이 생기지 않게 경계를 또렷하게 한다. 정확한 배경색과 이진 알파는 raw 의 책임이 아니다.
2. 원본을 `source/` 에 받은 그대로 두고 편집·리사이즈하지 않는다.
3. **캔버스 전체를 96×72 에 대응시킨다.** 1440×1080 이면 15×15 칸이 정확히 한 픽셀이다. 원본이 4:3 이 아닐 때만 가운데 기준으로 4:3 까지 자르고 좌표를 기록한다.
4. 원본 해상도에서 배경을 분리하고 마젠타 쪽으로 기운 가장자리 픽셀을 제거한다.
5. **보간 없이** 줄인다(칸별 최빈색). 새 색을 만들지 않는다.
6. 색 계열별로 스냅한다. 초록 계열 → top 팔레트, 흙·암반 계열 → E0 팔레트, 금속 계열 → 금속 표. **필수 11색은 강제 보존**한다.
7. 알파는 0 또는 255. 팔레트에 배경색이나 마젠타 쪽 색이 남으면 실패다.
8. 검사: 0~3행과 68~71행 비어 있음, 화석 윗끝 4~10행, 아랫끝 61~67행, 나선 중심 22~32행·50~64열, 재질 면적 비율 기록.
9. 결과는 시험 데코레이션으로만 쓰고, 플레이 판정 뒤에 승격한다.

## 8. 합성 계획 (정규화 이후, 게임 쪽 작업)

assembly_v3 의 전경은 자리표시용 도식에 맞춘 개념도다. **그 픽셀 형태를 raw04 에 그대로 적용하지 않는다.**

### 진행 순서

1. raw04 생성
2. 96×72 로 정규화
3. 정규화된 raw04 의 실제 알파, 외곽, 갈빗살, 부착물 위치를 분석
4. 배치 위치마다 E0 와 top 의 픽셀 위상을 맞춰 전경을 다시 파생
5. 게임에서 합성해 플레이로 판정

### 레이어

| 겹 | 내용 | 레이어 |
| --- | --- | --- |
| 화석 본체 | 정규화된 raw04 96×72 | `behind` |
| 위치별 블렌딩 | 표면 위: E0·top 에서 파생한 가림 픽셀. 표면 아래: inner 창으로 드러나는 raw04 픽셀과 top 이끼띠를 끊는 E0 픽셀 | `above` |

- 뒤 레이어만 쓰면 표면 아래 화석이 지형에 모두 가려지므로, raw04 의 일부 픽셀을 위치별 블렌딩에 복사한다. 새 그림은 필요 없다.
- E0 와 top 은 렌더러와 같은 좌표(`월드 − 연결 성분 원점`)로 샘플하고, 배치마다 기본 지형 캡처와 100% 일치하는지 확인한다.
- 좌우 반전으로 배치하면 반전된 화석에 맞춰 전경을 다시 파생한다.

### 접촉 구역

- 전경이 화석의 둥근 외곽을 일정하게 따라가면 테두리나 후광처럼 보이므로 금지한다.
- **크기가 서로 다른 접촉 구역 3~5 곳**에서만 지형이 화석 안쪽으로 침투한다.
- **왼쪽:** raw04 에 그려진 이끼가 실제 top 이끼로 이어진다. 아래는 조밀하고 위로 갈수록 성기게 끊긴다. 외곽 전체를 선처럼 따라가지 않는다.
- **중앙:** top 이끼와 작은 E0 암반이 화석 하단을 불규칙하게 교차한다. raw04 의 흙·이끼 오염에서 실제 지형으로 이어진다. 나선 중심은 가리지 않는다.
- **오른쪽:** raw04 에 붙은 E0 암반이 실제 inner 세로 결로 이어진다. 연속된 암반 면 → 깨진 경계 → 드문 암반 픽셀의 3단계로 동화한다. 오른쪽 아래 외곽의 약 25~35% 를 불규칙하게 잠식한다. 단순한 세로 돌기나 삼각형 받침은 금지. 암반 구간이 끝나면 기존 top 이끼가 다시 이어진다.
- 지면 위로 솟는 E0 암반은 2~8px, 지형 실루엣은 거의 평평하게 유지한다.

### 순수 inner 안의 노출

- 순수 inner 영역(표면 16px 아래)에서 화석이 **최소 3개의 분리된 창**으로 보인다.
- 아래 외곽 전체가 하나의 선으로 드러나지 않는다.
- E0 의 세로 결이 화석 조각 사이를 통과한다.
- raw04 의 흙·암반 오염색이 주변 E0 와 연결된다.

### 배치 조건

- 윗면이 평평한 구간이 **폭 140px 이상**, 표면 아래 솔리드가 **40px 이상**인 곳에 둔다. 96px 화석과 오른쪽 3단계 동화 폭이 들어가야 한다.
- raw01~03 시험에 쓴 두 곳은 폭이 좁아(작은 단 110px, 굴다리 앞 틈 70px) 맞지 않는다.
- 후보: 기본 지면(윗면 y=520, 두께 80px) 중 다른 솔리드가 없는 x 1600~8200 구간. 정확한 x 는 정규화 뒤 시험 때 정한다. 기준점은 `(x, 552)` 다.

## 10. 판정 기준

최종 게임 화면에서 확인한다.

- 하나의 대표 암모나이트 화석으로 읽히는가
- 깨끗한 금속 오브젝트처럼 따로 놀지 않는가
- raw04 의 이끼와 흙이 실제 top 과 inner 로 자연스럽게 이어지는가
- 화석이 top 을 관통해 inner 까지 박혀 보이는가
- 화석과 지형 이미지의 경계를 쉽게 찾을 수 없는가
- 큰 둔덕, 받침돌, 곧은 수평 절단선, 외곽 테두리가 없는가
- 충돌 없는 장식이라는 점이 플레이를 오해하게 하지 않는가
