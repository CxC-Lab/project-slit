## 축소 배율과 팔레트 매핑

**기본 배율: 원본 7.0px = 게임 1px (E0 보다 1.5배 덜 축소).**

| 배율 | 같은 색 가로 구간 평균 | 가장 큰 어두운 틈 | 가장 큰 밝은 면 |
| --- | --- | --- | --- |
| E0 (10.45) | 2.04 | 19×120 | 15×32 |
| **1.5배 (7.0)** | **2.79 (+37%)** | 34×179 | 23×49 |
| 2배 (5.225) | 3.51 (+72%) | 45×240 | 30×65 |

- 원본은 격자에 정렬된 확대본은 아니지만 약 10~12px 크기의 굵은 픽셀 질감이다. **덜 줄일수록 패치의 픽셀 덩어리가 주변 inner 보다 굵어진다**(해상도 불일치, 믹셀).
- 2배는 같은 색 구간이 72% 길어져 패치가 저해상도 조각처럼 보일 위험이 크다. 1.5배는 37% 로 중앙값(2px)이 E0 와 같다. 그래서 **1.5배를 기본**으로 하고 2배는 파생 단계에서 비교용으로만 한 번 만든다.
- **매핑은 E0 와 같은 방식이다.** 셀 중심 최근접 샘플(`nearest_point_center`) 뒤 14색 중 RGB 제곱거리 최근접, 동점이면 앞 번호(`nearest_palette_rgb`, `squared_rgb_first_tie`). 새 색을 만들지 않는다.
- 단순히 E0 를 확대한 모양이 되지 않도록, 아래 후보 영역의 **원본 속 실제 큰 틈과 암반 면**을 1.5배 크기로 가져온다. 파생 단계에서 E0 확대본과 나란히 비교한다(GO/NO-GO 1단계).

- 같은 종류는 같은 구조물 안에서 **240px 이상** 떨어뜨린다. 한 화면(800×450)에 같은 종류는 하나만 둔다.

## 이진 알파 마스크 규칙

사각형 전체를 불투명하게 쓰지 않는다. 파생 단계는 다음 순서로 마스크를 만든다(재현 가능한 규칙만 쓰고 손으로 칠하지 않는다).

1. **핵심 구조**를 정한다.
   - M1: 가장 긴 어두운 틈 성분 + 그 틈에서 2px 안의 암반 면
   - M2: 가장 큰 밝은 면 성분 + 그 바로 아래 어두운 띠
   - M3: 큰 균열 2개 + 작은 균열 + 그 사이 면
2. 핵심에서 바깥으로 영역을 넓히되 **어두운 틈(P00~P02) 픽셀에서 멈춘다.** 그래서 패치의 바깥 윤곽이 암반 사이 틈을 따라 끊긴다. 틈에서는 기존 inner 도 어두우므로 이음매가 숨는다.
3. 불투명 비율이 bbox 의 **45~70%** 가 되면 멈춘다.
4. bbox 가장자리 2px 안의 픽셀은 핵심 구조가 아니면 비운다. 사각형 외곽이 읽히지 않게 하려는 것이다.
5. 핵심에 속하지 않는 내부 중간색 영역(12px² 이상)은 비워 **기존 E0 의 미세 질감이 구멍으로 보이게** 한다.

## 자동 검사

| 검사 | 기준 |
| --- | --- |
| 팔레트 | 모든 불투명 픽셀이 E0 14색 중 하나 |
| 알파 | 0/255 만 |
| 불투명 비율 | bbox 의 45~70% |
| **사각형 외곽** | bbox 네 변 각각 불투명 점유 ≤ 40%, 외곽선의 최장 직선 구간 ≤ 8px |
| **이음매 대비(스티커 검사)** | 패치 경계를 건너는 이웃 픽셀의 평균 밝기 차 ≤ 같은 영역 inner 이웃 간 평균 차의 1.3배(실제 배치 화면에서 측정) |
| **해상도(믹셀)** | **알파 마스크 적용 전** 팔레트 매핑 이미지에서 같은 색 가로 구간 평균 ≤ E0 의 1.4배(2.86 이하). 마스크 적용 뒤 값도 기록하지만 합격 판정은 적용 전 값으로 한다(알파 구멍이 색 구간을 잘라 쉽게 통과하는 것을 막는다) |
| 좌우 반전 차이 | ≥ 30% (반전본을 같은 화면에 쓸 때 필수) |
| 금지 형태 | 한쪽 끝에서 반대쪽 끝까지 잇는 직선 경계, 일정 폭 세로 띠(폭 변동 < 2px 가 40행 이상) 없음 |

불통과 항목은 지우지 않고 provenance 에 남긴다. 육안 예외는 사용자 판정으로만 한다.

120px 세로 자기상관은 **패치 단독 이미지에서는 재지 않는다.** M1 높이가 130 이라 120 칸 떨어진 비교 구간이 10행뿐이어서 유효하지 않다. 이 값은 아래 기둥2 시험 ROI 에서만 잰다.

모든 좌표는 월드 좌표이고, 패치 사각형은 순수 inner 100% 위에 있으며 기존 장식 ±8px 와 겹치지 않는다(검증 완료). 데코레이션 기준점은 이미지 아래 가장자리 중앙이므로 `position = (x0 + W/2, y1)` 이다.
