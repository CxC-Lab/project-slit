## 이번에 만들 것: 매달린 덩굴 3종

한 장에 세 종류를 **가로로 나란히** 그린다. 원본 캔버스는 **1440x1080**, 게임 픽셀 1칸 = 원본 10x10 이다. 서로 원본 기준 120px 이상 떨어뜨린다.

| 종류 | 런타임 캔버스 | 원본 크기 | 형태 |
| --- | --- | --- | --- |
| V1 짧은 덩굴 | 20x36 | 200x360 | 잎이 적고 짧게 갈라진다. 줄기 1~2 가닥 |
| V2 중간 덩굴 | 24x56 | 240x560 | 두세 갈래로 나뉘고 갈래 길이가 서로 다르다 |
| V3 긴 갈래 덩굴 | 32x80 | 320x800 | 중심 줄기 하나와 가는 보조 줄기. 아래 끝이 같은 높이로 정렬되지 않는다 |

폭은 위 값이 상한이다. 실제 잎이 차지하는 폭은 V1 12~20px, V2 16~24px, V3 20~32px 범위다.

### 부착과 방향

- 덩굴은 **암벽 아랫면이나 돌출부에서 아래로 매달린다.** 위에서 아래로 자란다.
- **위쪽 끝**: 암반 틈에 붙은 짙은 뿌리 덩어리다. 캔버스 맨 위 3행 안에 있어야 하고 폭은 캔버스 폭의 50% 이상이다. 이 줄이 지형 아랫면에 닿는다.
- **아래로 갈수록** 가늘고 성기게 끝난다. 끝은 잎 몇 장과 가는 줄기다.
- 각 줄기의 길이와 잎 배치는 비대칭이다. 곧은 세로선, 일정한 간격의 반복, 좌우 대칭을 만들지 않는다.
- 세 종류가 이어 붙여 하나의 커튼이 되지 않게, 서로 다른 실루엣으로 그린다.

### 밧줄로 보이지 않게

- 굵기가 일정한 한 줄짜리 수직선을 만들지 않는다. 밧줄, 사다리, 체인처럼 보이면 실패다.
- 잎과 가는 곁줄기를 중심으로 표현하고, 중심 줄기도 마디마다 굵기가 달라진다.
- 가로 방향 규칙적인 마디(사다리 발판처럼 보이는 것)를 넣지 않는다.

## 색

승인된 top 이끼 팔레트만 쓴다. 투명 제외 **8색 이하**.

| 용도 | RGB | 규칙 |
| --- | --- | --- |
| 뿌리·그늘 | `(27, 46, 33)` | 필수 |
| 짙은 녹색 | `(31, 55, 36)` | 필수 |
| 중간 올리브 | `(51, 80, 40)` | 필수 |
| 중간 녹색 | `(89, 127, 36)` | 필수 |
| 추가 허용 | `(40, 65, 40)` `(60, 94, 39)` `(73, 109, 38)` `(113, 148, 36)` | 선택 |
| 밝은 연두 | `(142, 170, 41)` `(177, 188, 61)` | **끝부분과 작은 잎에만.** 합쳐서 불투명 픽셀의 5% 이하 |

- 짙은 녹색과 중간 올리브가 중심이다. 위쪽이 어둡고 아래·끝으로 갈수록 밝아진다.
- 위에서 오는 빛만 쓴다. 좌우 방향 그림자를 넣지 않는다.

## 그리지 않을 것

- 암반, 지면, top 이끼띠를 함께 굽지 않는다. 덩굴만 그린다
- 꽃, 열매, 발광, 네온, 청록색 식물
- 밧줄·사다리·체인처럼 보이는 형태, 잡을 수 있는 손잡이
- 곧은 세로선, 일정한 반복, 좌우 대칭
- 눈, 얼굴, 글자, 숫자, 서명
- 원근법, 비스듬한 시점, 입체 렌더링, 부드러운 그라데이션, 안티에일리어싱, 흐림

## 배경과 알파

- 배경은 전체를 선명한 마젠타 단색(`#FF00FF` 에 가까운 색)으로 채운다. 그라데이션·그림자·무늬 없이 단색이다.
- 덩굴과 배경 사이에 섞인 중간색, 번짐, 후광이 생기지 않게 경계를 또렷하게 한다.
- 정확한 배경색과 이진 알파는 raw 의 책임이 아니다. 정규화가 처리한다.

## 게임 쪽 정보 (참고)

- 레이어는 지형 위·플레이어 뒤(`above`)다. 덩굴이 캐릭터를 가리지 않는다.
- 기준점은 이미지 **아래 가장자리 중앙**이므로, 배치 좌표는 `부착 y + 캔버스 높이` 로 계산한다.
- 좌우 반전: V1·V2 는 허용한다. V3 는 실루엣이 특징적이라 한 화면에 반전본과 원본을 같이 쓰지 않는다.
- 카메라 밖이면 그리지 않는다. 충돌과 `solids` 는 바뀌지 않는다.

## 정규화 계약

1. 원본을 `source/` 에 받은 그대로 두고 편집·리사이즈하지 않는다.
2. 배경을 분리하고 마젠타 쪽으로 기운 가장자리 픽셀을 제거한다.
3. 남은 덩어리를 연결 성분으로 3개 분리한다. 왼쪽부터 V1, V2, V3 로 본다.
4. 성분마다 bbox 를 잡고 **보간 없이** 1/10 로 줄인다(셀 최빈색). 새 색을 만들지 않는다.
5. 각 캔버스(20x36, 24x56, 32x80)에 **위쪽 정렬·가로 중앙**으로 넣는다. 뿌리가 맨 위 행에 닿아야 한다.
6. 색을 top 팔레트에 스냅한다. 필수 4색은 강제 보존하고, 밝은 연두 2색 합계가 5% 를 넘으면 실패다.
7. 알파는 0 또는 255. 팔레트에 배경색이나 마젠타 쪽 색이 남으면 실패다.
8. 검사: 캔버스 크기, 위 3행 뿌리 폭 50% 이상, 열별 아래 끝 높이의 표준편차 4px 이상(정렬 금지), 한 열에서 이어지는 불투명 길이가 캔버스 높이의 70% 이하(곧은 세로선 금지), 좌우 반전본과의 픽셀 차이 30% 이상(대칭 금지), 색 전부 top 팔레트.
9. 결과는 `runtime/trials/` 시험 에셋으로 두고 플레이 판정 뒤 승격한다.
