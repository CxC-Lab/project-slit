# CxC Lab 브랜드 자산

이 디렉터리는 CxC Lab의 브랜드 자산을 보관한다.

- `cxc-lab-logo-compact.png`: GitHub Organization 썸네일, 파비콘, 작은 아이콘처럼 축소 표시되는 환경을 위한 광륜 없는 버전
- `cxc-lab-logo-halo.png`: 큰 프로필, 표지, 발표자료와 영상처럼 광륜을 식별할 수 있는 환경을 위한 확장 버전

두 로고는 동일한 브랜드 마크의 반응형 변형이다. Project Slit의 메인 README에는 로고를 표시하지 않는다. 로고를 임의로 재생성하거나 비율, 배치 또는 색상을 변경하지 않는다.
