# Project Slit

Project Slit은 CxC Lab에서 진행하는 1인 연구개발 프로젝트입니다. 이중슬릿 실험에서 영감을 받은 현재의 이름은 내부 코드네임이며, 최종 제품명은 아닙니다.

현재는 게임 제품을 본격적으로 개발하는 단계가 아닙니다. 독립적인 기술 실험과 Unit Test를 준비하고, 검증된 결과만 향후 게임의 기반으로 발전시키는 초기 단계입니다. 기술 스택, 플랫폼, 렌더링 API, 네트워크 구조와 아트 스타일은 아직 확정되지 않았습니다.
