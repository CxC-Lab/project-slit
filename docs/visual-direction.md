# Project Slit 비주얼 방향

![Project Slit 최초 게임플레이 콘셉트](../assets/concept-art/project-slit-gameplay-concept-v001.png)

이 문서는 최초 게임플레이 콘셉트 아트에서 읽을 수 있는 방향과 향후 검증할 질문을 기록한다. 이미지는 최종 게임 화면이나 확정된 구현 사양이 아니다.

## 이미지에서 읽을 수 있는 방향

- 2D 사이드뷰 기반의 횡방향 탐험
- 캐릭터보다 압도적으로 큰 폐허와 구조물
- 전경, 중경, 원경 레이어를 이용한 깊이감
- 경사면과 다층 플랫폼이 연결된 이동 공간
- 작고 귀여운 플레이어 캐릭터와 거대한 세계의 대비
- 비, 무지개, 안개와 같은 날씨와 대기 표현
- 따뜻한 황금빛 하늘과 주홍빛 식생
- 화면을 압도하는 수직 구조와 멀리 이어지는 이동 가능 공간
- 플레이어가 제한된 수만큼 보유하고 월드에 설치하는 깃발
- 멀리 있는 다른 플레이어와 말풍선으로 표현된 가벼운 조우
- 목적지나 퀘스트보다 이동과 발견 자체를 강조하는 경험

## 이 이미지로 확정하지 않는 사항

- 최종 픽셀 크기와 화면 해상도
- 캐릭터의 최종 디자인과 종족
- 실제 UI 배치와 깃발 아이콘
- 특정 색상 팔레트
- 타일 크기와 충돌 구조
- 배경 레이어의 실제 개수
- DirectX와 HLSL의 구체적인 렌더링 방식
- 후처리와 날씨 효과의 구현 방법
- 지역의 최종 설정과 스토리
- 이미지에 표현된 모든 구조물이 실제로 이동 가능한지 여부

## 구현 과정에서 검증할 질문

- 작은 캐릭터가 복잡한 배경에서도 명확하게 보이는가?
- 장거리 이동 중 배경 변화가 반복적으로 느껴지지 않는가?
- 거대한 수직 구조물이 실제 이동 경로와 자연스럽게 연결되는가?
- 비와 후처리가 플레이 가독성을 방해하지 않는가?
- 깃발과 다른 플레이어의 말풍선이 배경보다 과도하게 튀지 않는가?
- 패럴랙스와 다중 레이어 구성이 성능 목표를 만족하는가?
- 콘셉트의 화면 밀도를 유지하면서 충돌 지형은 단순하게 구성할 수 있는가?
