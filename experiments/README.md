# 기술 실험

각 실험은 하나의 가설을 가능한 한 작고 독립적으로 검증한다. 제품 코드나 공용 프레임워크를 먼저 만들지 않으며, 성공과 실패 모두 결과로 기록한다.

## 실험 기록 형식

```markdown
# 실험 제목

- 상태: 제안 | 진행 중 | 완료 | 중단
- 날짜: YYYY-MM-DD

## 목적

이 실험으로 알아내려는 것은 무엇인가?

## 가설

검증 가능하고 반증 가능한 예상은 무엇인가?

## 범위

포함하는 것과 의도적으로 제외하는 것은 무엇인가?

## 성공 조건

어떤 관측 결과를 성공으로 판단하는가?

## 테스트 방법

어떤 입력, 경계값과 반복 절차로 검증하는가?

## 결과

측정값, 실패 사례와 재현 방법은 무엇인가?

## 후속 결정

결과에 따라 채택, 수정, 폐기하거나 다음에 실험할 것은 무엇인가?
```

## 첫 실험 후보: 음수 좌표를 포함한 월드 좌표와 청크 좌표 변환

월드 좌표를 청크 인덱스와 청크 내부 좌표로 일관되게 분해하고 다시 조합할 수 있는지 검증한다. 특히 정수 나눗셈과 나머지 연산의 언어별 동작 때문에 발생할 수 있는 음수 좌표 경계 오류를 확인한다.

후보 성공 조건은 다음과 같다.

- 청크 내부 좌표가 항상 `0 <= local < chunkSize`를 만족한다.
- `-chunkSize`, `-1`, `0`, `chunkSize - 1`, `chunkSize`를 포함한 경계값이 예상한 청크에 속한다.
- 좌표를 분해한 뒤 다시 조합하면 원래 월드 좌표와 일치한다.

구현 언어, 청크 크기와 테스트 프레임워크는 아직 선택하지 않는다. 이 항목은 실험 후보 기록이며 코드 구현이 아니다.

## 후속 실험 후보: 이동과 2인 공중 급유

아래 순서는 확정된 개발 일정이 아니라 이동과 협력 경험을 작은 단계로 분리해 검증하기 위한 후보 순서다. 각 단계는 앞선 결과가 유효할 때만 다음 실험으로 승격한다.

1. 걷기
2. 달리기
3. 점프
4. 8방향 공중 대쉬
5. 연속 공중 대쉬
6. 체공
7. 급강하
8. 공중 자원 게이지
9. 2인 멀티플레이 위치 동기화
10. `F` 기반 원형 상호작용
11. 상대 플레이어 공중 자원 충전
12. 먼 거리에서 추락 중인 플레이어 구조
13. 필요성이 확인된 이후 벽타기, 매달리기와 지상 슬라이드

첫 2인 멀티플레이 실험에서는 완성된 캐릭터 그래픽 대신 임시 사각형을 사용할 수 있다. 다음 경험만 우선 검증한다.

- 두 플레이어가 서로 보이고 독립적으로 이동한다.
- 한 플레이어의 공중 이동이 자원을 소모한다.
- 다른 플레이어가 `F` 상호작용으로 그 자원을 회복시킨다.
- 먼 거리에서 추락 중인 플레이어를 구조해 공중 이동으로 복귀시킬 수 있다.

## 후속 실험 후보: 공통 스프라이트 규격

이 실험은 이동 규칙을 임시 사각형으로 먼저 검증한 뒤, 테스트 아바타 한 종으로 공통 스프라이트 규격이 성립하는지 확인한다. 특정 캔버스 크기, 프레임 수 또는 atlas 배치를 확정하는 실험이 아니다.

1. 임시 사각형으로 이동 시스템 검증
2. 고정 크기 프레임을 가진 테스트 아바타 한 종 적용
3. Idle, Walk와 Run 애니메이션 전환
4. Jump와 Air Dash 적용
5. 공통 pivot의 시각적 흔들림 검증
6. collider와 sprite 분리 검증
7. 2프레임 Music 애니메이션 적용
8. 다른 2~4종 아바타를 같은 규격으로 교체할 수 있는지 검증

성공 조건 후보는 모든 프레임의 캔버스와 pivot이 일관되고, `visualOffset`이 물리 상태를 바꾸지 않으며, 아바타 교체 시 animation state나 atlas 해석 코드를 변경하지 않는 것이다.
