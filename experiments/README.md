# 기술 실험

각 실험은 하나의 가설을 가능한 한 작고 독립적으로 검증한다. 제품 코드나 공용 프레임워크를 먼저 만들지 않으며, 성공과 실패 모두 결과로 기록한다.

## 실험 기록 형식

```markdown
# 실험 제목

- 상태: 제안 | 진행 중 | 완료 | 중단
- 날짜: YYYY-MM-DD

## 목적

이 실험으로 알아내려는 것은 무엇인가?

## 가설

검증 가능하고 반증 가능한 예상은 무엇인가?

## 범위

포함하는 것과 의도적으로 제외하는 것은 무엇인가?

## 성공 조건

어떤 관측 결과를 성공으로 판단하는가?

## 테스트 방법

어떤 입력, 경계값과 반복 절차로 검증하는가?

## 결과

측정값, 실패 사례와 재현 방법은 무엇인가?

## 후속 결정

결과에 따라 채택, 수정, 폐기하거나 다음에 실험할 것은 무엇인가?
```

## 첫 실험 후보: 음수 좌표를 포함한 월드 좌표와 청크 좌표 변환

월드 좌표를 청크 인덱스와 청크 내부 좌표로 일관되게 분해하고 다시 조합할 수 있는지 검증한다. 특히 정수 나눗셈과 나머지 연산의 언어별 동작 때문에 발생할 수 있는 음수 좌표 경계 오류를 확인한다.

후보 성공 조건은 다음과 같다.

- 청크 내부 좌표가 항상 `0 <= local < chunkSize`를 만족한다.
- `-chunkSize`, `-1`, `0`, `chunkSize - 1`, `chunkSize`를 포함한 경계값이 예상한 청크에 속한다.
- 좌표를 분해한 뒤 다시 조합하면 원래 월드 좌표와 일치한다.

구현 언어, 청크 크기와 테스트 프레임워크는 아직 선택하지 않는다. 이 항목은 실험 후보 기록이며 코드 구현이 아니다.
